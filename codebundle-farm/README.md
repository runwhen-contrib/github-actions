# CodeBundle Farm Actions

GitHub Actions that power the [CodeBundle Farm](https://github.com/stewartshea/codebundle-farm)
autonomous CodeBundle creation and quality system.

| Action | Description |
|--------|-------------|
| [`score-v2`](./score-v2/) | Score CodeBundle quality against a 100-point rubric |

Future actions (as the system grows):

- **creator** — Trigger Creator agent (Architect / SRE mode) from issue events
- **intake** — Route incoming issues through the `rw-codebundle-agent` GitHub App
