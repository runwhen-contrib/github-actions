# github-actions
This repository hosts all public GitHub Actions that can be used by platform users and authors. 

## Available Actions

- [CodeCollection Score](./codecollection-score/README.md) - Analysis and scoring for CodeCollection authors
- [Generate Release](./generate-release/README.md) - Date-based GitHub releases with auto-incrementing versions
- [Publish PyPI](./publish-pypi/README.md) - Build and publish Python packages to PyPI with date-based versioning
